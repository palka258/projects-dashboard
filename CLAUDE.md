# Дашборд проектов — инструкция для Claude

Это личный дашборд пользователя со статусами его проектов. Публикуется через GitHub Pages.
Единственный источник данных — `projects.json`. `index.html` его просто отображает, в коде страницы менять нечего.

## Когда пользователь просит обновить статус проекта

1. Открой `projects.json`.
2. Найди нужный проект по `id`/`name` (или создай новый объект в массиве `projects`, если проекта ещё нет).
3. Обнови поля:
   - `status`: `"done"` | `"in_progress"` | `"todo"`
   - `stages`: список этапов, каждый `{ "title": "...", "status": "done|in_progress|todo", "note": "..." (необязательно) }`
   - `updatedAt`: сегодняшняя дата в формате `YYYY-MM-DD`
4. Обнови верхнеуровневое поле `updated` в `projects.json` на сегодняшнюю дату.
5. Закоммить и запушь изменения — GitHub Pages сам подхватит новую версию `projects.json`.

## Правила

- Не переусложняй `stages` — 3-6 этапов на проект достаточно.
- Пиши коротко и по-русски, как в остальном файле.
- Не трогай `index.html`/стили без явной просьбы — это чисто отображение.
- Если пользователь просит добавить новый проект — просто добавь новый объект в массив `projects` по образцу существующих.
